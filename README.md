# LM Chat

Android-клиент для общения с локальным сервером [LM Studio](https://lmstudio.ai/). Телефон и компьютер должны быть в одной сети. Сервер LM Studio при этом принимает подключения из локальной сети.

Минимальная версия Android — 12 (API 31).

## Что умеет

- Переписка с выбранной моделью. Ответ приходит потоком и остаётся внизу экрана. Если прокрутить историю вверх, автопрокрутка останавливается.
- Ответы модели показываются с разметкой Markdown: заголовки, жирный и курсив, списки, цитаты, код и таблицы. Таблица из строк `| столбец | столбец |` рисуется сеткой; если она шире экрана, её можно прокрутить вбок. Жирный текст внутри ячеек сохраняется. Линия `---` становится разделителем.
- Несколько чатов: кнопка «Новый чат» и список истории. У чата название берётся из первого сообщения, чат можно открыть снова или удалить.
- Изображения из галереи. Картинка сжимается и отправляется вместе с текстом на модели со зрением.
- Выбор модели из списка сервера. Загруженная модель и поддержка зрения отмечены в списке.
- Настройки: адрес сервера, API-key, имя пользователя, свои инструкции, лимит токенов и показ рассуждений. Имя и инструкции уходят в системное сообщение. Если показ рассуждений выключен, запрос идёт с `reasoning_effort: none`, и модель отвечает сразу.

Запросы идут на OpenAI-совместимый endpoint `POST /v1/chat/completions`. Список моделей читается из `GET /api/v1/models`.

## Сборка

Откройте папку проекта в Android Studio и запустите конфигурацию `app` на телефоне или эмуляторе с Android 12+.

Из командной строки, если установлены JDK 17 и Android SDK:

```bash
./gradlew assembleDebug
```

Готовый debug-APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Подключение к LM Studio

1. В LM Studio запустите локальный сервер и разрешите доступ из локальной сети.
2. В приложении откройте настройки и укажите адрес вида `http://192.168.x.x:1234` и API-key сервера.
3. Нажмите «Проверить связь», сохраните настройки и выберите модель в чате.

Адрес и API-key, указанные в настройках, можно изменить в любой момент.
